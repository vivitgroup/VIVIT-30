# UI/UX Hardcore Audit Gate

This repository treats core interaction ergonomics as a release contract. The automated gate covers navigation focus return, minimum primary touch targets, mobile safe areas, keyboard-operable notifications, live-region semantics, VIVITO naming consistency, and creative media dialog behavior. It complements the broader HTML ten-pass, mobile UX, resilience UX, RBAC, TypeScript, lint and production build gates.

A passing static gate is not a substitute for screenshot-based visual regression testing. Pixel-level rendering must be certified separately when browser screenshot automation is available.
